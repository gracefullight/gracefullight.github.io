Monte Carlo Methods​

  • A Computational technique that uses random sampling and statistical methods to solve complex problems and estimate numerical results.
    • Named after the Monte Carlo Casino in Monaco.
    • It means Estimate an unknown quantity by sampling, and averaging what you observe.
  • Used fo any estimation method whose operation involves a significant random component.
  • Used in mathematics, physics, engineering, finance, computer science, etc.
  • It is particularly valuable when an analytical solution is difficult or impossible to obtain.

  • Updates the value function V(s)V(s)V(s) incrementally after each trajectory without requiring memory to store individual past returns.
  • Algorithmic Flow:
    • Initialize N(s)←0N(s) \leftarrow 0N(s)←0 and V(s)←0V(s) \leftarrow 0V(s)←0 for all s∈Ss \in Ss∈S.

      • N(s)←N(s)+1N(s) \leftarrow N(s) + 1N(s)←N(s)+1 (Increment counter for total visits)
      • V(s)←V(s)+α(Gi,t−V(s))V(s) \leftarrow V(s) + \alpha (G_{i,t} - V(s))V(s)←V(s)+α(Gi,t​−V(s)) (Update the value by mean return)
      • Where Gi,t−V(s)G_{i,t} - V(s)Gi,t​−V(s) represents the temporal difference (TD) error between the sampled return target and the current estimate.
  • Choice step size α\alphaα
    • α=1N(s)\alpha = \frac{1}{N(s)}α=N(s)1​: Replicates the exact empirical sample-average of Every-Visit MC where all observed samples receive equal weight.

    • Requires a significant number of episodes to converge to the true value function.

General Policy Iteration​

  • Alternates between Policy Evaluation (V≈vπV \approx v_\piV≈vπ​ or Q≈qπQ \approx q_\piQ≈qπ​) and Policy Improvement (π←greedy\pi \leftarrow \text{greedy}π←greedy).
  • This interplay drives the system asymptotically toward the optimal pair (v∗,π∗)(v_*, \pi_*)(v∗​,π∗​) or (q∗,π∗)(q_*, \pi_*)(q∗​,π∗​).

π′(s)=argmaxa∈A(R(s,a)+γ∑s′∈SP(s′∣s,a)V(s′))\pi'(s) = \text{argmax}_{a \in A} \big( \mathcal{R}(s, a) + \gamma \sum_{s' \in S} \mathcal{P}(s' | s, a) V(s') \big)π′(s)=argmaxa∈A​(R(s,a)+γ∑s′∈S​P(s′∣s,a)V(s′))

  • Why V(s)V(s)V(s) Fails in Model-Free Settings:
    • Finding the maximizing action over V(s)V(s)V(s) strictly requires the transition model P(s′∣s,a)P(s' \mid s, a)P(s′∣s,a) and reward function R(s,a)R(s, a)R(s,a).
    • In Model-Free RL, these dynamics are unavailable; hence, V(s)V(s)V(s) alone cannot guide policy updates without an explicit environment model.

π′(s)=argmaxa∈AQ(s,a)\pi'(s) = \text{argmax}_{a \in A}Q(s,a)π′(s)=argmaxa∈A​Q(s,a)

  • Model-Free Advantage:
    • By estimating Q(s,a)Q(s, a)Q(s,a) directly through sample episodes, policy improvement requires no knowledge of PPP or RRR.
    • This fundamental shift makes Q(s,a)Q(s, a)Q(s,a) estimation the standard paradigm for Model-Free Control (Monte Carlo Control, SARSA, Q-Learning).

Exploration Problem​

a=arg⁡max⁡aQ(s,a)a = \arg\max_a Q(s,a)a=argamax​Q(s,a)
  • A greedy agent always chooses the action with the highest current estimated value.
  • But what if the current Q(s,a)Q(s,a)Q(s,a) estimates are inaccurate?

Mystery Box Example​

Initially,

Q(red)=0,Q(blue)=0Q(\text{red}) = 0, \qquad Q(\text{blue}) = 0Q(red)=0,Q(blue)=0

  1. Open the red box:
    R=0→Q(red)=0R = 0 \rightarrow Q(\text{red}) = 0R=0→Q(red)=0

  2. Open the blue box:
    R=+1→Q(blue)=1R = +1 \rightarrow Q(\text{blue}) = 1R=+1→Q(blue)=1

  3. Keep opening the blue box:
    R=+1,+3,+2,…→Q(blue)≈2R = +1, +3, +2, \ldots \rightarrow Q(\text{blue}) \approx 2R=+1,+3,+2,…→Q(blue)≈2

  4. A purely greedy agent now keeps choosing the blue box because
    Q(blue)>Q(red)Q(\text{blue}) > Q(\text{red})Q(blue)>Q(red).

  5. However, the red box may actually be better. For example,
    E[R∣red]=5\mathbb{E}[R \mid \text{red}] = 5E[R∣red]=5.

    The agent does not know this because it sampled the red box only once.

Exploitation vs. Exploration​

  • Exploitation: Choose the action that currently has the highest estimated value.
  • Exploration: Try less-sampled or unfamiliar actions to discover whether they may actually be better.
  • In this example, the agent should occasionally explore the red box because it has not been sampled enough to confidently conclude that it is worse.

DP vs MC​

  • Dynamic Programming:
    • Model-based
    • Bootstrapping: Updating a value estimate using another estimated value instead of waiting for the final outcome.
    • Lower variance
  • Monte Carlo:
    • Model-free
    • No bootstrapping
    • Uses complete sampled returns
    • Requires episodic tasks
    • Higher variance
