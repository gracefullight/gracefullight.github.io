Markov Property​

  • The future is independent of the past given the present state.
  • The current state is sufficient to determine the future, without history.

Markov State​

P[St+1∣St]=P[St+1=s′∣St=s]P[S_{t+1} | S_t] = P[S_{t+1} = s' | S_t = s]P[St+1​∣St​]=P[St+1​=s′∣St​=s]

  • ttt: Time step
  • St+1S_{t+1}St+1​: Next state
  • StS_tSt​: Current state
  • S1,…,StS_1, \ldots, S_tS1​,…,St​: History (All previous states)

State Transition Probability​

Pss′=P[St+1=s′∣St=s]P_{ss'} = P[S_{t+1} = s' | S_t = s]Pss′​=P[St+1​=s′∣St​=s]

  • Likelihood or probability of moving from one state sss to another state s′s's′ in the next time step t+1t+1t+1.
  • sss: Markov State
  • s′s's′: Successor State
  • ttt: Time step
  • State transition matrix PPP defines the transitions probabilities between all states sss to all successor states s′s's′.

Markov Process​

Markov Chain

  • What is going to be happened next?
  • it goes through a sequence of states overtime.
  • Stochastic Process: The next state St+1S_{t+1}St+1​ is determined by the current state StS_tSt​ and the transition probability matrix PPP that exhibits the Markov Property.
  • Current state is independent of the past states.
  • Memoryless: History of states leading up to the current state is not necessary to predict the next/future state.
  • MP: ⟨S,P⟩\langle\mathcal{S},\mathcal{P}\rangle⟨S,P⟩, What states comes next?, Observer's Perspective.
  • MRP: ⟨S,P,R,γ⟩\langle\mathcal{S},\mathcal{P},\mathcal{R},\gamma\rangle⟨S,P,R,γ⟩, How good/How much reward is this state in the long run?, Evaluator's Perspective.
  • MDP: ⟨S,A,P,R,γ⟩\langle\mathcal{S},\mathcal{A},\mathcal{P},\mathcal{R},\gamma\rangle⟨S,A,P,R,γ⟩, What action should I take right now to maximize the long-term reward?, Decision Maker's Perspective.

  • SSS: a finite set of states.

Markov Reward Process​

Markov Chain + Reward

⟨S,P,R,γ⟩\langle\mathcal{S},\mathcal{P},\mathcal{R},\gamma\rangle⟨S,P,R,γ⟩

  • SSS: a finite set of states.
  • P\mathcal{P}P: a state transition matrix (Transition Dynamics)
  • R\mathcal{R}R: a reward function to compute expected reward from a state.
    • Rs=E[Rt+1∣St=s]\mathcal{R}_s = \mathbb{E}[R_{t+1} | S_t = s]Rs​=E[Rt+1​∣St​=s]
    • In the state sss, how much reward can you expect to get in the next time step?
  • γ\gammaγ: a discount factor, to balance the immediate and future rewards.
    • γ∈[0,1]\gamma \in [0, 1]γ∈[0,1]

Return​

Gt=Rt+1+Rt+2+⋯+RTG_t = R_{t+1} + R_{t+2} + \cdots + R_TGt​=Rt+1​+Rt+2​+⋯+RT​

  • GtG_tGt​: Goal Reward
    • The sum of the rewards received from time step ttt.
  • Rt+1,Rt+2,…,RTR_{t+1}, R_{t+2}, \ldots, R_TRt+1​,Rt+2​,…,RT​: the sequence of rewards received after time step ttt
  • TTT: terminal state
  • ttt: time step

Discount​

  • The present value of future rewards.
  • γ=0\gamma = 0γ=0: Myopic evaluation for maximizing immediate reward.
  • γ=1\gamma = 1γ=1: Far-sighted/Long-term evaluation for maximizing future reward.

Gt=Rt+1+γRt+2+γ2Rt+3+⋯+γT−t−1RT=∑k=0∞γkRt+k+1G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots + \gamma^{T-t-1} R_T = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}Gt​=Rt+1​+γRt+2​+γ2Rt+3​+⋯+γT−t−1RT​=∑k=0∞​γkRt+k+1​

  • GtG_tGt​: Discounted Return
  • γ=1\gamma = 1γ=1: Undiscounted Markov Reward Process, if all sequences terminate (like games)

Value Function​

v(s)=E[Gt∣St=s]v(s) = \mathbb{E}[G_t | S_t = s]v(s)=E[Gt​∣St​=s]

  • The expected return from state sss.
  • How much total reward can you expect to get starting from this state?
  • A function returning the expected cumulative reward starting from state sss

Markov Decision Process​

Markov Reward Process + Actions(Decisions)

⟨S,A,P,R,γ⟩\langle\mathcal{S},\mathcal{A},\mathcal{P},\mathcal{R},\gamma\rangle⟨S,A,P,R,γ⟩

  • SSS: a finite set of states.
  • A\mathcal{A}A: a finite set of actions.
  • P\mathcal{P}P: a state transition matrix
    • Pss′a=P[St+1=s′∣St=s,At=a]\mathcal{P}_{ss'}^a = P[S_{t+1} = s' | S_t = s, A_t = a]Pss′a​=P[St+1​=s′∣St​=s,At​=a]
  • R\mathcal{R}R: a reward function
    • Rsa=E[Rt+1∣St=s,At=a]\mathcal{R}_s^a = \mathbb{E}[R_{t+1} | S_t = s, A_t = a]Rsa​=E[Rt+1​∣St​=s,At​=a]
  • γ\gammaγ: a discount factor

Policy​

π(a∣s)=P[At=a∣St=s]\pi(a | s) = P[A_t = a | S_t = s]π(a∣s)=P[At​=a∣St​=s]

  • Policy specifies what actions to take in each state.
    • π(left∣wall)=0.8\pi(\text{left} | \text{wall}) = 0.8π(left∣wall)=0.8
    • π(right∣wall)=0.2\pi(\text{right} | \text{wall}) = 0.2π(right∣wall)=0.2
    • π(straight∣wall)=0.0\pi(\text{straight} | \text{wall}) = 0.0π(straight∣wall)=0.0
    • The agent's playbook for any given state.
  • It fully defines the behavior of the agent.
  • MDP's policy does not depends on history, only on the current state.

  • The state value function vπ(s)v_\pi(s)vπ​(s) is the expected return starting from state sss and following policy π\piπ.
  • How good it is to be in state sss (under policy π\piπ)?

Solving MDPs​

Goal: Find optimal policy π∗\pi_*π∗​ that maximizes the expected return.

  • Using Value Iteration or Policy Iteration.
  • Updating value functions and policies iteratively until convergence.
  • Evaluation: Compute the value function vπ(s)v_\pi(s)vπ​(s) for a given policy π\piπ.
  • Improvement: Update the policy π\piπ to choose better actions based on the updated value function.
    • To converge to the optimal value function and policy v∗,π∗v^*, \pi^*v∗,π∗

POMDPs​

MDPs with hidden states.

⟨S,A,O⏟공간 (Spaces),P,R,Z⏟함수 / 규칙 (Functions),γ⏟상수 (Discount Factor)⟩\langle \underbrace{\mathcal{S}, \mathcal{A}, \mathcal{O}}_{\text{공간 (Spaces)}}, \underbrace{\mathcal{P}, \mathcal{R}, \mathcal{Z}}_{\text{함수 / 규칙 (Functions)}}, \underbrace{\gamma}_{\text{상수 (Discount Factor)}} \rangle⟨공간 (Spaces)S,A,O​​,함수 / 규칙 (Functions)P,R,Z​​,상수 (Discount Factor)γ​​⟩

  • SSS: a finite set of states
  • A\mathcal{A}A: a finite set of actions
  • O\mathcal{O}O: a finite set of observations
    • e.g. driving in foggy weather.
  • P\mathcal{P}P: a state transition matrix
  • R\mathcal{R}R: a reward function
  • Z\mathcal{Z}Z: an observation function
    • Zs′,oa=P[Ot+1=o∣St+1=s′,At=a]\mathcal{Z}_{s', o}^a = P[O_{t+1} = o | S_{t+1} = s', A_t = a]Zs′,oa​=P[Ot+1​=o∣St+1​=s′,At​=a]
    • an observation function specifying the probability of receiving observation ooo given state s′s's′ and action aaa
    • After taking action aaa and landing in state s′s's′, how likely is the agent to observe ooo?
  • γ\gammaγ: a discount factor
  • e.g.
    • Robot navigation with noisy/uncalibrated sensors.
    • Autonomous Driving with Sensor uncertainty due to bad weather conditions and unexpected events.

Finite Horizon MDPs​

  • Finite Time Steps (TTT): A sequential decision-making process restricted to a fixed, finite number of steps (TTT) to maximize cumulative rewards.
  • Target Applications: Well-suited for problems with explicit deadlines or time-varying environment dynamics.
  • Decision Basis: Optimal decisions are made using current state (StS_tSt​), available actions (AtA_tAt​), transition probabilities (P\mathcal{P}P), and immediate rewards (R\mathcal{R}R).
  • Representative Example: A robot navigating a grid world with a limited step count or battery budget to reach a goal while avoiding obstacles.
  • Discount Factor (γ\gammaγ): Because the horizon TTT is finite, the cumulative return cannot diverge to infinity, allowing the use of undiscounted formulations (γ=1\gamma = 1γ=1).
  • Time-Dependent (Non-Stationary) Policy:
    • Unlike infinite-horizon MDPs, the optimal action depends explicitly on the remaining time steps (T−tT - tT−t).
    • Policy Notation: πt(s)\pi_t(s)πt​(s) (indexed by time step ttt).
    • Intuition: An agent may play conservatively early on, but take high-risk, high-reward actions right before the deadline.

Limitations of MDPs​

  • Markovian Assumption: Assumes future transitions depend solely on the current state StS_tSt​, ignoring past historical trajectories and temporal dependencies that matter in real-world dynamics (e.g., momentum, acceleration).
    • State augmentation, frame stacking, RNN/Transformer, POMDP
  • Complete Knowledge Requirement: Assumes exact a priori knowledge of transition probabilities P\mathcal{P}P and reward functions R\mathcal{R}R, which are rarely accessible without sample-based learning in complex environments.
    • Model-free RL: Q-learning, SARSA, Policy Gradient
  • Finite State and Action Spaces: Restricted to discrete and countable sets, whereas real-world robotics and physical control tasks typically involve continuous states and actions.
    • Function approximation, Actor-Critic: DDPG, TD3, SAC, PPO
  • Curse of Dimensionality: Tabular value and policy storage scale exponentially as state dimensions grow (∣S∣×∣A∣|\mathcal{S}| \times |\mathcal{A}|∣S∣×∣A∣), making high-dimensional environments (e.g., raw pixel inputs) computationally intractable.
    • Deep RL: neural approximation of VVV, QQQ, or π\piπ
  • Partial Observability: Assumes full access to the true ground-truth state (Ot=StO_t = S_tOt​=St​), failing to account for real-world sensor noise, occlusions, and incomplete observations.
    • POMDP, belief-state estimation, recurrent policies
